# 🎨 Claude Desktop MCP 工具使用 - 图形界面指南

## 📍 在 Claude Desktop 中找到 MCP 工具

### 方法 1：查找 MCP 图标

Claude Desktop 通常会在以下位置显示 MCP 连接状态：

1. **输入框附近的图标**
   - 查找 🔌 插头图标
   - 或者 🔧 工具图标
   - 或者 "MCP" 文字标识

2. **输入框内的提示**
   - 有些版本会在输入框内显示 "可用工具" 或 "MCP"

3. **右上角或左上角**
   - 查找设置或工具菜单

### 方法 2：使用 @ 符号（如果支持）

某些版本的 Claude Desktop 支持使用 `@` 符号来调用工具：

```
@add 计算 5 + 3
@query 查询数据库表数量
```

### 方法 3：在对话中明确提及

**最可靠的方法** - 在对话中明确说明：

```
你：我想使用 MCP 工具。请告诉我有哪些工具可用？

你：请使用 add 工具计算 5 + 3

你：调用 query 工具，参数如下：
    question: "数据库中有多少张表？"
    return_type: "result"
```

## 🧪 测试命令（按顺序尝试）

### 第 1 步：确认工具可见性

```
我看到你连接了 MCP 服务器。请列出所有可用的工具。
```

或者：

```
你能看到 test-add 这个 MCP 服务器吗？它提供了什么工具？
```

### 第 2 步：明确调用工具

```
请调用 add 工具，参数 a=5, b=3
```

或者更详细：

```
我想测试 MCP 连接。请执行以下操作：
1. 使用 add 工具
2. 传入参数 a=10, b=20
3. 返回结果
```

### 第 3 步：自然语言 + 明确指令

```
请帮我计算 5 + 3，使用 MCP 的 add 工具来完成
```

## 📋 不同场景的提问模板

### 场景 1：查看可用工具

```
模板 1：你连接了哪些 MCP 服务器？每个服务器提供什么工具？
模板 2：列出所有可用的 MCP 工具及其功能
模板 3：我想知道你能调用哪些外部工具
```

### 场景 2：调用简单工具（add）

```
模板 1：请调用 add 工具计算 5 + 3
模板 2：使用 MCP 的 add 函数，参数 a=10, b=20
模板 3：执行 add(100, 200) 并返回结果
```

### 场景 3：调用数据库工具（query）

```
模板 1：请使用 query 工具查询数据库中有多少张表
模板 2：调用 MCP 的 query 工具，问题是："显示所有表名"
模板 3：使用数据库查询工具，执行以下查询：
        问题：数据库中有多少条记录？
        数据库：blog_small
        返回类型：result
```

### 场景 4：仅生成 SQL（不执行）

```
模板 1：使用 query 工具生成 SQL，但不执行：
        问题：查找最近 7 天的文章
        返回类型：sql

模板 2：请调用 query 工具，参数如下：
        question: "统计每个作者的文章数"
        return_type: "sql"
```

## 🎯 关键短语

在提问时包含这些短语，Claude 会更容易理解你想使用 MCP 工具：

- ✅ "请使用 MCP 工具"
- ✅ "调用 [工具名] 工具"
- ✅ "使用 [工具名] 函数"
- ✅ "执行 [工具名]"
- ✅ "通过 MCP 查询"
- ✅ "使用外部工具"

## 🔍 如何确认 Claude 看到了 MCP 工具

### 测试 1：直接询问

```
你：你能看到 test-add 这个 MCP 服务器吗？

预期回复：
✅ 是的，我可以看到 test-add 服务器，它提供了 add 工具
❌ 我看不到任何 MCP 服务器（说明连接有问题）
```

### 测试 2：要求列出工具

```
你：请列出你当前可以使用的所有工具和功能

预期回复：
✅ 应该包含 "add 工具" 或 "test-add 服务器"
❌ 只列出内置功能（说明 MCP 未连接）
```

### 测试 3：尝试调用

```
你：请调用 add 工具计算 5 + 3

预期回复：
✅ [显示工具调用] 结果是 42
❌ 我没有 add 工具（说明连接有问题）
```

## 🐛 如果 Claude 仍然说"看不到工具"

### 步骤 1：完全重启 Claude Desktop

```bash
# 强制退出
killall Claude

# 等待 5 秒
sleep 5

# 重新启动
open -a Claude

# 等待 10 秒让 MCP 服务器完全启动
sleep 10
```

### 步骤 2：检查 MCP 服务器进程

```bash
# 查看 MCP 服务器是否在运行
ps aux | grep "main.py"

# 应该看到类似这样的输出：
# ronny  98855  ... /Users/ronny/.local/bin/uv --directory ... run python main.py
```

### 步骤 3：查看 Claude Desktop 日志

```bash
# 查看最新的 MCP 日志
ls -lt ~/Library/Logs/Claude/ | head -5

# 查看日志内容
tail -50 ~/Library/Logs/Claude/mcp-server-test-add.log
```

### 步骤 4：验证配置文件

```bash
# 显示配置
cat ~/Library/Application\ Support/Claude/claude_desktop_config.json

# 验证 JSON 格式
python3 -m json.tool ~/Library/Application\ Support/Claude/claude_desktop_config.json
```

## 💡 专业提示

### 提示 1：使用结构化的请求

```
你：我想测试 MCP 连接，请按以下步骤操作：

步骤 1：确认你能看到 test-add 服务器
步骤 2：列出该服务器提供的工具
步骤 3：调用 add 工具，参数 a=5, b=3
步骤 4：告诉我返回的结果
```

### 提示 2：提供完整的工具调用信息

```
你：请调用 MCP 工具，详细信息如下：

服务器：test-add
工具名：add
参数：
  - a: 10
  - b: 20
```

### 提示 3：如果不确定工具名称

```
你：我的 MCP 配置中有一个叫 test-add 的服务器。
    请告诉我它提供了什么工具，以及如何使用这些工具。
```

## 📊 成功标志

当 MCP 工具正常工作时，你会看到：

1. ✅ Claude 的回复中包含 **工具调用的详细信息**
2. ✅ 显示 **工具名称、参数、返回值**
3. ✅ 可能有 **特殊的视觉标识**（如工具图标、高亮显示）
4. ✅ Claude 会说 "我调用了 XXX 工具" 或显示工具执行过程

## 🎬 完整示例对话

```
你：你好，我配置了一个 MCP 服务器叫 test-add。你能看到它吗？

Claude：是的，我可以看到 test-add 服务器。它提供了一个 add 工具。

Claude：[调用 add 工具]
      工具：add
      参数：a=5, b=3

      计算结果是 42。

你：完美！现在请帮我切换到完整的数据库服务器
```
